# ADR-004: Append-only click events aggregated at read time

Status: accepted (brownfield scenario)

## Decision

Store one row per successful redirect; compute stats with GROUP BY on request.

## Rationale

Always consistent, trivially correct, cheap at internal volumes (indexed by code+time). The AnalyticsRepository interface allows swapping to a stream + rollup table without touching callers.

## Alternatives considered

- Pre-aggregated counters per day (fast reads, harder to add new dimensions, update contention)
- External analytics pipeline (operational overhead out of proportion to need)

## Consequences

Table grows unbounded until a retention policy is agreed (recorded as residual risk).
