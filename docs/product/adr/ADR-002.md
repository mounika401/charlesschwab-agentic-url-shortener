# ADR-002: Random base62 codes from a CSPRNG

Status: accepted (greenfield scenario)

## Decision

7-character codes drawn with secrets.choice over [A-Za-z0-9]; bounded retry on collision.

## Rationale

3.5e12 code space makes collisions negligible at internal volumes and codes cannot be enumerated, satisfying 'not guessable in sequence'.

## Alternatives considered

- Auto-increment id encoded in base62 (enumerable, leaks volume)
- Hash of URL (same URL always maps to same code; collisions need handling anyway)
