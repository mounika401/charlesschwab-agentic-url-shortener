# ADR-006: Fix BUG-101 test-first, before wiring analytics

Status: accepted (brownfield scenario)

## Decision

Write the regression test as its own task, then fix resolve() ordering, then add events.

## Rationale

Proves the bug exists and is fixed; prevents the new analytics from inheriting the defect.

## Alternatives considered

- Fix and test in one change (no evidence the test would have caught the bug)
