# ADR-007: Syntactic destination safety policy

Status: accepted (ambiguous scenario)

## Decision

Reject credentials-in-URL, internal hostnames, non-global IP literals, own domain and a configured blocklist, without DNS resolution.

## Rationale

Deterministic, fast, and never makes the service perform network I/O on behalf of clients. Covers the phishing and internal-target classes the requester named.

## Alternatives considered

- Resolve DNS and check the resolved IP (latency, SSRF-by-resolver, still racy vs. rebinding)
- Third-party reputation API (vendor + network dependency; out of scope per clarification)

## Consequences

Names that resolve to private IPs are not caught (residual risk, documented).
